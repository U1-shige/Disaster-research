# 災害復旧事業特別調査システム

## 概要

本システムは、国土交通省が所掌する**災害復旧事業**において、**重要変更協議**が適切に行われているかを調査・管理するために開発された支援ツールです。

広島県庁土木局が主体となり、県内における災害復旧事業の適正な執行を確保することを目的としています。

---

## 背景

近年、広島県内では豪雨・土砂災害等の自然災害が頻発しており、多数の災害復旧事業が実施されています。  
これらの事業において、設計内容の変更が生じた場合、所定の手続きに従った**重要変更協議**の実施が求められますが、現場の実態と手続きの整合性について継続的な確認が必要です。

本調査は、事業執行上の課題を早期に把握し、適正な事業管理に資することを目的としています。

---

## 主な調査対象

### 災害復旧事業の種別

| 種別 | 内容 |
|------|------|
| 河川災害復旧事業 | 河川施設（堤防・護岸・水制等）の被災復旧 |
| 道路災害復旧事業 | 道路施設（路体・路床・擁壁・橋梁等）の被災復旧 |
| 砂防設備災害復旧事業 | 砂防えん堤・流路工等の被災復旧 |
| 海岸災害復旧事業 | 海岸堤防・護岸・突堤等の被災復旧 |
| 急傾斜地崩壊防止施設災害復旧事業 | 急傾斜地崩壊防止施設の被災復旧 |

### 調査の重点事項

- 重要変更協議の要否判断の適切性
- 協議書類の整合性・完全性
- 協議時期の適時性（工事着手前の協議実施）
- 変更後の設計内容と現場施工の整合
- 事業費・工期の変更管理状況

## 用語集

### 災害復旧事業関連

| 用語 | 説明 |
|------|------|
| **査定設計書** | 被災施設の復旧工法・設計内容を記載した書類。国土交通省（または農林水産省）の査定を経て、国庫負担の基礎となる |
| **重要変更** | 査定設計書の内容から工法・構造・規模等が大幅に変更となる場合に、改めて国との協議が必要となる変更 |
| **軽微変更** | 重要変更に該当しない範囲での軽微な設計変更。県限りで処理可能 |
| **現地査定** | 国土交通省の査定官が被災現場に赴き、復旧工法・設計の妥当性を審査する手続き |
| **机上査定** | 書類審査のみで行われる査定。比較的被害規模が小さい場合等に適用 |
| **事業費確定** | 完成した災害復旧事業について、最終的な国庫負担額を決定する手続き |
| **国庫負担率** | 災害復旧事業費に対する国の負担割合。通常2/3、著しく激甚な災害では引き上げ措置あり |
| **激甚災害** | 「激甚災害に対処するための特別の財政援助等に関する法律」に基づき指定される災害。国庫補助率の引き上げ等の特例措置が適用される |
| **工法変更** | 当初査定を受けた施工方法から変更する場合の手続き。重要変更に該当するか否かの判断が重要 |
| **流用** | 査定を受けた箇所から他の箇所への事業費の充当。原則として不可 |
| **転用** | 事業完了後、当該施設を他の目的に使用すること。原則として不可 |

### 手続き関連

| 用語 | 説明 |
|------|------|
| **重要変更協議** | 重要変更に該当する設計変更について、国土交通省地方整備局との間で行う事前協議 |
| **協議書** | 重要変更協議において提出する書類。変更理由・変更内容・変更前後の比較等を記載 |
| **協議完了** | 国土交通省地方整備局から協議成立の通知を受けた状態。協議完了前の工事着手は不可 |
| **事前着手** | 協議完了前に工事に着手すること。不適切な事前着手は国庫負担の対象外となる可能性がある |
| **変更査定** | 当初査定後に重要変更が生じた場合に実施する追加の査定手続き |

## 調査フロー

```
被災発生
    │
    ▼
被害状況の把握・応急処置
    │
    ▼
査定設計書の作成
    │
    ▼
国土交通省による現地査定（または机上査定）
    │
    ▼
工事発注・着工
    │
    ▼
設計変更の要否判断
    │
    ├── 軽微変更 ─→ 県限りで処理
    │
    └── 重要変更 ─→ 重要変更協議（協議完了後に変更工事着手）
                          │
                          ▼
                     事業完了・検査
                          │
                          ▼
                     事業費確定（国庫負担額の確定）
```

---

## 重要変更協議の判断基準

以下のいずれかに該当する変更は、**重要変更**として協議が必要です。

1. **工法の変更** ― 査定工法と根本的に異なる工法への変更
2. **規模の変更** ― 断面・延長・高さ等が査定規模を著しく超える変更
3. **位置の変更** ― 施工箇所の位置が大幅に変わる変更
4. **構造形式の変更** ― 例：重力式護岸からブロック積護岸への変更等
5. **事業費の増減が一定割合を超える変更**

## 関連法令・通達

- 公共土木施設災害復旧事業費国庫負担法（昭和26年法律第97号）
- 公共土木施設災害復旧事業費国庫負担法施行令
- 公共土木施設災害復旧事業費国庫負担法施行規則
- 激甚災害に対処するための特別の財政援助等に関する法律（昭和37年法律第150号）
- 災害復旧事業費の算定に関する指針（国土交通省）
- 公共土木施設災害復旧事業費国庫負担申請等に関する事務取扱要領
